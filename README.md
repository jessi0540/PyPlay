# PyPlay - Automatización con Playwright y POM

Proyecto para automatizar el registro de usuarios en [Parabank](https://parabank.parasoft.com/parabank).

## 🧱 Estructura del proyecto

- `pages/`: lógica de páginas (POM)
- `tests/`: pruebas automatizadas
- `utils/`: configuraciones y utilidades
- `conftest.py`: fixtures globales para pruebas

## 🚀 Instalación

```bash
pip install -r requirements.txt
playwright install
